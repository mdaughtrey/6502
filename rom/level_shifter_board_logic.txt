Address Buffers:

A = RP2350
B = 6502

RW = 1, read from RAM 
RW = 0, write to RAM

TR = 1, A->B = RP2350->RAM
TR = 0, B->A = RAM->RP2350

BE->6502 = 0, 6502 bus is high impedance
BE->6502 = 1, 6502 bus is active
OE = 0, busses connected
OE = 1, busses isolated

When RP2350 is writing to RAM
BE = 0                  ; Disconnect 6502 from Address and Data busses
Address TR = 1          ; Set Address RP2350->6502
Data TR = 1             ; Set Data RP2350->6502
Address OE = 0          ; Connect Address Bus
Data OE = 0             ; Connect Data Bus
Assert Address Bus
Assert Data Bus
RW = 0                  ; Set bus write to RAM
Clock = 0               ; clock in the data to RAM
Clock = 1               ; ...
Data OE = 1             ; Disconnect Data Bus
Address OE = 1          ; Disconnect Address Bus
Address TR = 0          ; Set Address 6502->RP2350
Data TR = 0             ; Set Data 6502->RP2350
BE = 1                  ; Enable 6502 Address and Data busses


When RP2350 is reading from RAM
BE = 0                  ; Disconnect 6502 from Address and Data busses
Address TR = 1          ; Set Address RP2350->6502
Data TR = 0             ; Set Data 6502->RP2350
Address OE = 0          ; Connect Address Bus
Data OE = 0             ; Connect Data Bus
Assert Address Bus
RW = 1                  ; Set bus read from RAM
Read from Data Bus
Address OE = 1          ; Disconnect Address Bus
Data OE = 1             ; Disconnect Data Bus
Address TR = 0          ; Set Address 6502->RP2350
BE = 1                  ; Enable 6502 Address and Data Busses

When RP2350 is monitoring address bus
Address TR = 0          ; Set Address 6502->RP2350
Address OE = 0          ; Connecdt Address Bus
Read Address Bus
